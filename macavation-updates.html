Macavation Web Portal · Modernisation Review
Prepared by CustomApp · July 2026

Before & After · Front-end release

The same portal, made to feel modern.

Since the last release we've reworked how the Macavation portal looks and feels — how you move around it, how every screen behaves, and how it's laid out. This is a front-end change only: your data, your calculations and your workflows are untouched. The result is a cleaner, more consistent system that's quicker to learn and unmistakably Macavation.

01

One clear way to get around

Navigation was the first thing everyone touched and the first thing that felt dated.

Before

A top bar stacked on top of a side menu — two competing navigation zones. Every page load also flashed a burst of colourful outlined cards before the real content appeared.

After

A single full-height sidebar with the Macavation wordmark. Tools and your profile sit neatly in the footer, the account menu flies out cleanly, and the screen loads calm — no flashing.

02

Search that works the same everywhere

Finding a batch, a supplier or an order should feel identical no matter which module you're in.

Before
  • Every module searched differently — cramped strips with no labels, flat toolbars, filters hidden behind a "Filters" toggle.
  • Duplicate "Apply" buttons that did nothing the typing hadn't already done.
  • The Board / Table switch turned up in a different place each time.
After
  • One search-and-filter card across the whole portal — labelled fields, a Clear button always in the same spot.
  • Filters are always visible; results update as you type.
  • The Board / Table switch lives in the search bar, every time. Learn it once.
03

Clarity over clutter

Dense screens were doing more to hide the work than to help it.

Before
  • Thin, hard-to-read card headers; module titles and buttons that didn't line up.
  • More buttons on screen than anyone used.
  • Long figures ran together — 2345678.
  • Oversized panels (silos, production calendar) pushed the actual work off-screen.
After
  • Modern, legible headers; each module opens with its title and one clear primary action, aligned.
  • Numbers grouped for reading — 2 345 678.
  • Space-heavy panels folded into compact, on-demand icon menus — the work stays front and centre.
04

A portal that looks like Macavation

The shell was generic. Now the brand is present from the first screen.

Before

A plain, utilitarian shell that could have belonged to any system — nothing that said this was Macavation's.

After

A branded sign-in with custom macadamia line-art, the pink Macavation wordmark throughout, and softly branded dialog backdrops. It reads as Macavation's own tool — not an off-the-shelf template.

05

Works in the dark, too

A full dark theme — for early mornings, the packhouse floor, and anyone who simply prefers it.

Before

One fixed, always-bright appearance — no matter the setting, the screen, or the time of day.

After

A complete dark mode across every screen — switched in a click and remembered next time. Contrast and the brand green were tuned for dark just as carefully as for light, so nothing gets lost.

06

The same building blocks everywhere

Tables, dialogs and status labels were subtly different from screen to screen. Now they're one kit.

Before
  • Row actions differed table to table — some crowded the row, others were hard to find.
  • Pop-up confirmations and alerts came in a mix of looks.
  • Status labels were styled inconsistently, and a few badges were visually broken.
After
  • Every table row uses the same tidy "⋯" actions menu.
  • One consistent style for all confirmation dialogs and alerts.
  • Status shown as clear, colour-coded pills — the same everywhere — with proper loading and empty states instead of blank screens.
07

The finishing touches

The small inconsistencies that quietly made the portal feel unfinished.

Before
  • The help button sat in a different place on every screen — or was missing.
  • Some cards had coloured outlines, others didn't, with no rule behind it.
  • Admin carried a "System" tab that did nothing and a "Last login" column that was always empty.
After
  • A single "?" help icon, in the same place beside every heading.
  • Card outlines calmed to one neutral style across the board.
  • The empty tab and column removed — less to wade through, nothing that misleads.

How it stays this way

Consistency that holds as the portal grows

The new look isn't hand-applied screen by screen — it comes from one shared set of design rules, with an automated check that runs on every change.

◆One design system

Colours, spacing, buttons and cards are defined once and reused everywhere, so a change to the standard updates the whole portal — not twenty separate copies.

◆Enforced automatically

A built-in check (ui:verify) flags anything that drifts off-standard before it ships, so the portal keeps looking like one product as new features are added.
