# BluePrint — baseline docs for a Customapp portal

The reference docs every portal project follows. Start with `10_STEP_BLUEPRINT.md`, then the
jQuery/Supabase rules. `model-delegation/` sets the Sonnet builder/recon delegation model.

This is the generic baseline. Specialist guides (auth integrations, QA phase playbooks, mobile
responsiveness, user-management, etc.) live in `Customapp-PTY-LTD/BrokerPortal-standard/BluePrint/`
— copy in the ones a given project needs rather than carrying all of them in every repo.
