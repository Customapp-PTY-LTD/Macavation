Import historical kernel data

Load kernel batches from Macadamia Kernel Statistics Excel (e.g. for go-live).

  1. Export the kernel batch sheet from Excel to CSV (one row per batch; columns: Batch, Grower, Received Date, Finished Date, SP, 0, 1, 1S, 4L, 5, 6, 7/8, B.High, B.Low).
  2. Run node scripts/import-historical-kernel-from-csv.js your-file.csv to generate SQL.
  3. Run the generated SQL in Supabase MCP (execute_sql) or the Supabase SQL Editor.
