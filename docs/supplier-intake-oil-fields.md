# Supplier Intake Module — Oil Table Fields Used

Based on the supplier intake grid, Receiver checklist, New batch modal, Quality test modal, and `data-functions.js`, these are the **oil table fields** used for **display** and **functionality** in the Supplier Intake module.

---

## 1. Fields used for **display** (grid, Kanban, detail popup, export)

| Oil table field | How it’s used in Supplier Intake |
|-----------------|-----------------------------------|
| **id** | Row identity; passed to View/Edit/Sample test/Release; `data-batch-id` and `oil_id` in quality test context. |
| **batch_id** | Shown as **Batch #** (table + Kanban); search/filter; export column `batch_number`. |
| **status** | Drives Kanban column (awaiting_test → “Awaiting tests”, release_ready → “Ready for Oil Production”); status filter; status badge; detail popup; export. |
| **production_date** | Fallback for “Date received” when `intake_data.date_received` is missing. |
| **intake_data** | Source for all intake-related display (see below). |
| **production_data** | `name_of_product` used as fallback for **Product type** when `intake_data.product_type` is missing. |

### Flattened from **intake_data** for display

The grid and detail view read these from `oil.intake_data` (mapped in `data-functions.js` `mapOilRowToGrid`):

| Display label | intake_data path / key |
|---------------|------------------------|
| Date received | `date_received` (or `oil.production_date`) |
| Delivery note / PO | `delivery_note_reference` or `delivery_note_ref` |
| Supplier | `supplier` or `supplier_details` |
| Product type | `product_type` (or `production_data.name_of_product`) |
| Quantity (kg) | `quantity_kg` or `items[0].quantity_kg` |
| Mfg / Best before | `manufactured_date`, `best_before_date` or `items[0].*` |
| Reference / PO | `reference` |
| Description | `description` |
| Carton / bulk bags | `carton_bulk_bags` |
| Receiving checks | `vehicle_checks.vehicle_clean`, `vehicle_enclosed`, `hazard_substances`, `pest_infestations`, `pallets_condition`, `raw_materials_condition` (or top-level `vehicle_clean` etc.) |
| Receiving comments | `receiving_comments` |

Export columns: `batch_number`, `product_type`, `date_received`, `delivery_note_ref`, `supplier_details`, `quantity_kg`, `status`.

---

## 2. Fields used for **functionality** (create / update / release)

### Creating batches (Receiver checklist — one oil row per bag row)

| Oil field | Set from |
|-----------|----------|
| **batch_id** | `data.batch_number` (per item) or auto-generated by `upsert_oil_batch`. |
| **production_date** | `data.date_received`. |
| **status** | `'awaiting_test'`. |
| **intake_data** | Full intake payload (see below). |
| **created_by** | Current user (when provided). |
| **updated_by** | Current user (when provided). |

### Creating/editing a single batch (New batch modal)

| Oil field | Create | Edit |
|-----------|--------|------|
| **batch_id** | `data.batch_number` or auto | `data.batch_number` (optional) |
| **production_date** | `data.date_received` | `data.date_received` |
| **status** | `'awaiting_test'` | Preserved from existing batch |
| **intake_data** | Form fields | Form fields; vehicle_checks and receiving fields preserved from existing |
| **created_by** | Current user | — |
| **updated_by** | Current user | Current user |

### Release to Oil Production

| Oil field | Value |
|-----------|--------|
| **status** | `'production'` |
| **updated_by** | Current user |

### After Sample test (Quality test modal) — move to “Ready for Oil Production”

| Oil field | Value |
|-----------|--------|
| **status** | `'release_ready'` |
| **updated_by** | Current user (via `updateOilBatchStatus`) |

### **intake_data** payload shape (create/update)

Written by Receiver checklist and New batch modal into `oil.intake_data`:

- `date_received`, `delivery_note_reference`, `delivery_note_ref`
- `supplier_id`, `supplier`, `supplier_details`
- `product_type`, `quantity_kg`
- `manufactured_date`, `best_before_date`
- `reference`, `description`, `carton_bulk_bags`
- `receiving_comments`
- `vehicle_clean`, `vehicle_enclosed`, `hazard_substances`, `pest_infestations`, `pallets_condition`, `raw_materials_condition`
- `vehicle_checks`: `{ vehicle_clean, vehicle_enclosed, hazard_substances, pest_infestations, pallets_condition, raw_materials_condition }`
- `delivery_group_id` (Receiver checklist only, for grouping)

## 3. Oil table fields **not** used by Supplier Intake

| Field | Note |
|-------|------|
| total_oil_litre | Not set or shown in Supplier Intake (used later in Oil Production). |
| production_data | Only read for `name_of_product` fallback; not written by Supplier Intake. |
| stock_data | Not written by Supplier Intake; may be used by Quality Test / QA elsewhere. |
| dispatch_data | Not used in Supplier Intake. |
| intake_completed_at | Not set in Supplier Intake flow. |
| production_completed_at, stock_completed_at, dispatch_completed_at | Not used in Supplier Intake. |
| is_active | Not changed by Supplier Intake (default true). |
| created_at, updated_at | Server-managed; not sent from client. |
| silos | Not used in Supplier Intake. |

---

## 4. Summary

- **Display:** `id`, `batch_id`, `status`, `production_date`, `intake_data`, and `production_data.name_of_product` (fallback).
- **Create/Update:** `batch_id`, `production_date`, `status`, `intake_data`, `created_by`, `updated_by`.
- **Release / Sample test:** only `status` (and `updated_by`) are updated; no other oil columns are written by the Supplier Intake module.
