Executive summary

Phase 1 gave Macavation a working portal for kernel and oil operations. Phase 2 adds planning visibility, tighter controls, and smarter alerts so the system guides daily decisions, not just records them.

A substantial portion of Phase 2 was already implemented in the repository before this sprint. Remaining work is deployment, business configuration, historical data loading, and targeted gap-filling.

Epic breakdown

Epic 1 — Historical data (2 years)

Trustworthy trend charts and runway backed by ~24 months of history. Kernel import RPC and CLI exist; oil import RPC added. Blocked on Pete data delivery.

Epic 2 — Advanced permissions

Button/action control per role — UI via action-access.js and API via role_permissions. Action keys seeded; role matrix workshop needed.

Epic 3 — In-app messaging

Notification inbox with read/unread; entity picker and link_params for deep links to batches, stock, grower intake.

Epic 4 — Stock red-flag alerts

Configurable thresholds; evaluate on stock grid load + scheduled cron; resolve UI; auto-clear when stock recovers.

Epic 5 — Daily reporting (email + WhatsApp)

Enriched digest: kernel, oil, alerts, procurement, runway, produced vs target. Email via Resend; WhatsApp via Meta Cloud API.

Epic 6 — Dashboard enhancements

Sound kernel recovery, oil yield, stock on hand, oil forecast chart, consolidated batch summary, produced vs target, runway, production trends.

Epic 7 — Shell waste tracking

Auto-create shell lots from production shell_total; dispatch workflow on kernel stock screen.

Epic 8 — Grower intake: mass balance & procurement

NIS-in vs cracked/packed; planned vs actual procurement variance; this-week summary card.

Epic 9 — Oil module

Batch search with date/status filters; consolidated batches with lab ref; release workflow polish.
