What the daily, weekly and monthly reports will look like on your phone — and what you can do with them.

Macavation produces three reports. This document shows you exactly what each one will look like when it arrives on a WhatsApp, who receives it, and what a person can do by replying.

Section 1

The three reports at a glance

The important difference is who presses send.

The daily report is just numbers off the factory floor. Nobody needs to read it before it goes out, so the system sends it on its own every afternoon at five. The weekly and monthly reports contain Pete's wording and his corrections to the figures, so those only leave the building when Pete has looked at them and pressed send himself. That stays exactly as it is today.

Worth knowing

The daily message and the weekly report will always agree with each other. Both take their figures from the same place in the system, so the Thursday daily and Friday's weekly report cannot end up quoting two different tonnages for the same day. That is deliberate, and it is the main reason the daily is being built inside the report system rather than as a separate little job.

Everyone does not get everything

You will have one list of people with a tick for each report they should receive. The factory team might get the daily only. A shareholder might get the weekly and monthly but not the daily. Pete manages that list himself in the portal — there is a picture of that screen on page 7.

What happens, in order

At five o'clock the system first pulls the latest figures off the factory system, then reads them back and sends the message. That order matters — it means the numbers on your phone are as fresh as the factory data, not a snapshot from whenever somebody last pressed refresh in the portal.

If Pete has corrected a figure

His correction wins. The five o'clock refresh only updates the raw factory mirror; it never overwrites a number a person has deliberately entered. So a figure Pete fixed this morning is still the figure that goes out this afternoon.

On a day with no production

Nothing gets sent. No Sunday message, no public holiday message, no "0 kg". If the factory did not run, your phone stays quiet.

If something goes wrong twice

You will not get the same day's figures twice. The system checks whether it has already sent today before it sends again.

One thing to decide

The message above shows four figures plus week to date: cracked, kernel packed, wholes percentage, and NIS received. That is my recommendation — it fits on a phone screen without scrolling and answers the question most people open it for.

If you want different figures, or more of them, now is the moment to say so. The wording and the list of figures have to be registered with WhatsApp before the first message can go out, and changing them afterwards means submitting it again and waiting for approval a second time.

Why it looks a little plainer than you might expect

WhatsApp will not let a business send you a message out of the blue in whatever words it likes. For an automatic message like this one, the wording has to be registered with WhatsApp in advance and approved by them. Once approved, only the numbers can change — the labels around them are fixed.

The practical effect is that the figures sit on their own lines as Cracked: 12 480 kg rather than lining up in a neat column. WhatsApp does not allow the spacing that a column needs. It reads perfectly well on a phone; it is just not a table.

How Pete sends it

He opens the report in the Sales & Production Report module, edits the figures and his commentary, writes the summary, then presses Publish and Send via WhatsApp. He picks who gets it from a list, and it goes.

A draft can never go out

The system refuses to send anything that has not been published. Once a report is on someone's phone there is no getting it back, so an unfinished draft is blocked outright.

The words are Pete's, the format is not

The message always carries the report name, the published date, Pete's summary and the link. Pete controls the summary. Nobody can change the rest of the wording, and nothing can be sent to a phone number under Macavation's name with wording that came from a web browser.

The link

The PDF itself is not attached — the message carries a private link to it that works for 30 days. The link is unique and not guessable, so it only works for someone you sent it to.

Pete can see who actually got it

Every send is recorded per person, with WhatsApp's own reason if one failed. Pete sees this in the report itself, and there is a button to retry just the ones that did not go through.

Same process, once a month

Exactly the same as the weekly

Same module, same editing, same Publish and Send, same delivery record, same 30-day link. The only differences are the period it covers and that the audience is usually a bit wider.

Correcting a report after it has gone out

Pete cannot quietly edit a report that has already been sent. Instead he presses Re-issue, gives a reason, and the system retires the old version and opens a fresh copy for him to correct. The old one is kept, marked as superseded.

This matters for a monthly that shareholders have already read: there is always a record of what was originally sent and why it changed.

A separate list

Monthly recipients are ticked separately from weekly ones. It is normal for someone to get the monthly and not the weekly.

Already working

Everything on this page and the previous page is already built and working on the test system. It is not part of the new work, apart from splitting the recipient list per report. The new work is the daily report, the replies, and the recipient screen.

Type a word, get an answer

Nothing can be changed by WhatsApp

Every one of these only reads information. There is no way to enter production figures, change a report, or send anything to anyone else from a handset. That is a deliberate limit — a phone is too easy to pick up.

Only known staff get figures

The system already knows which phone numbers belong to which staff member. Production figures only go to a number it recognises as staff. A shareholder who types WEEK gets a polite "not available", not the tonnage.

Anyone can stop it

STOP and HELP work for everybody on the list, staff or not. This is partly courtesy and partly practical: if someone cannot make it stop, they block the number, and then they never get the monthly report either.

MUTE instead of STOP

MUTE 7 pauses the daily for a week and then it resumes. Useful for someone on leave who does not want to be taken off the list altogether.

Every reply is recorded

Who asked, what they asked, and what they were told — including anything refused. Already built.

Reminder

REPORT only re-sends a link to someone who already received that report. It never gives anyone access to something they were not sent in the first place.

Two protections built into this list

  • The same person cannot be added twice. Saving someone as 082 555 0110 and again as +27 82 555 0110 is caught as the same number. Nobody gets a confidential report twice, and nobody gets missed because they were on the list under a different format.
  • Somebody stopping does not delete them. If a person replies STOP, their row stays, marked as stopped. Pete can see it happened rather than wondering where they went.

Section 7

What has to happen before this goes live

Four things stand in the way. None of them is a surprise or a problem — but the first one involves waiting for WhatsApp, so it should start early.

1. WhatsApp has to approve the daily message

WhatsApp does not allow a business to message somebody out of the blue in free wording. The daily report is exactly that: nobody asked for it, it just arrives at five. So the wording has to be submitted to WhatsApp and approved before the first one can be sent.

This is why the figure list on page 3 needs signing off now. Approval usually takes a day or two. Changing the wording later means going through it again.

Good news

I checked the messaging system we already use, and it can send approved messages like this without any change. I had expected that to be a piece of work; it is not. The only wait is WhatsApp's approval.

2. The report system is not on the live database yet

The whole Sales & Production Report module — the reports, the recipients, the delivery record, the daily figures table — currently exists only on the test system. It has to be moved across to the live one before anybody outside the project sees a message from it.

3. Replies currently arrive at the test system

The WhatsApp number is presently wired to the test database. If somebody replied today, the test system would answer them using test data. This gets pointed at the live system as part of going live.

4. Nothing in the system can run on a timer yet

There is no scheduler installed. It is a standard switch-on and takes minutes, but it has to be done on the test system first, then the demo one, then live — never live first.

What it costs to send

WhatsApp charges per conversation for a business-initiated message like the daily. For a handful of recipients once a day it is small money, but it is not zero and it scales with the number of people on the daily list. Worth knowing before the list grows to thirty people.
