# My Day Entry Management Guide

## Overview

The "My Day" dashboard displays personalized workflow items based on the user's role. Users can manage these entries through various actions.

## Entry Types and Management Options

### 1. **Workflow Tasks** (Today's Workflow)

**What they are:**
- Tasks assigned to the user's role
- Scheduled for today or specific times
- Can have action buttons to navigate to related modules

**Management Options:**
- ✅ **Mark as Complete** - Check the checkbox to mark a task as completed
- ⏰ **Snooze** - Click the clock icon to snooze the task for 1 hour (it will reappear later)
- ❌ **Dismiss** - Click the X icon to dismiss the task (removes from view, but can still be accessed from main module)
- 🔘 **Action** - Click the action button (if available) to navigate to the related module

**How it works:**
- Completed tasks are removed from the "Today's Workflow" view
- Snoozed tasks will reappear after 1 hour
- Dismissed tasks are marked as "dismissed" but remain in the database

### 2. **Due Items** (Due This Period)

**What they are:**
- Items with due dates that need attention
- Can be overdue (highlighted in red)
- Related to specific modules or workflows

**Management Options:**
- ✅ **Mark as Complete** - Click the checkmark icon to mark the item as completed
- ⏰ **Snooze** - Click the clock icon to reschedule the item for tomorrow (1 day later)
- ❌ **Dismiss** - Click the X icon to dismiss the item
- 👁️ **View** - Click the "View" button to navigate to the related module

**How it works:**
- Completed items are removed from the "Due This Period" view
- Snoozed items will reappear tomorrow with the new due date
- Dismissed items are removed from the user's view

### 3. **Watching Items** (Proactive Intelligence)

**What they are:**
- Items being monitored for trends or changes
- Show insights and trend indicators
- Generated by the proactive intelligence system

**Management Options:**
- ⏰ **Snooze** - Click the clock icon to snooze the item for 1 day
- ❌ **Stop Watching** - Click the X icon to stop watching this item
- 👁️ **View** - Click the "View" button to navigate to the related module

**How it works:**
- Snoozed items will reappear tomorrow
- Items you stop watching are deactivated and won't appear in your watching list

### 4. **Recent Activity** (Read-Only)

**What they are:**
- Recent actions and changes in the system
- Automatically generated based on user activity
- Shows what happened recently related to your role

**Management Options:**
- **Read-only** - These entries are informational only and cannot be managed

## User Interface

### Task Management Buttons

Each entry type has specific action buttons:

- **Checkbox** (Tasks only) - Mark as complete/incomplete
- **Clock Icon** ⏰ - Snooze the item
- **X Icon** ❌ - Dismiss/Stop watching
- **Checkmark Icon** ✅ (Due items only) - Mark as complete
- **View Button** 👁️ - Navigate to related module

### Visual Indicators

- **Overdue items** - Highlighted in red
- **Completed tasks** - Strikethrough or grayed out
- **Trend indicators** - Up/down arrows with percentages for watching items

## Best Practices

1. **Complete tasks promptly** - Mark tasks as complete when finished to keep your dashboard clean
2. **Snooze strategically** - Use snooze for items you want to handle later, not items you want to ignore
3. **Dismiss sparingly** - Only dismiss items you're certain you don't need to see
4. **Review regularly** - Check your "My Day" dashboard at the start of each day
5. **Use action buttons** - Click action buttons to quickly navigate to related modules

## Technical Details

### Database Functions Required

The following database functions must exist for full management functionality:

1. **`update_workflow_task`** - Update task status (completed, dismissed, pending)
2. **`update_due_item`** - Update due item status and due date
3. **`update_watching_item`** - Update watching item active status

### Status Values

- **Tasks**: `pending`, `completed`, `dismissed`
- **Due Items**: `pending`, `completed`, `dismissed`
- **Watching Items**: `is_active` (boolean)

### Auto-Refresh

The "My Day" dashboard automatically refreshes every 5 minutes to show the latest entries.

## Troubleshooting

**Q: I dismissed a task but it came back.**
A: Dismissed tasks are removed from your view, but if the system regenerates the task (e.g., a recurring task), it will reappear.

**Q: Can I undo a snooze?**
A: Currently, snoozed items will reappear at the scheduled time. To handle it immediately, you can navigate to the related module using the action button.

**Q: How do I add new tasks?**
A: Tasks are typically generated by the system based on your role and workflow. Contact your administrator if you need custom tasks added.

**Q: Can I edit task details?**
A: Task details are managed through the related modules. Use the action button to navigate to the module where you can make changes.
